## 1. Executive Summary & Business Context
Enterprise leadership teams are routinely flying blind when allocating growth capital, pricing interventions, or retention budgets. Traditional predictive machine learning (XGBoost, Random Forests) only captures *correlation*, leading to wasted campaign spend on customers who would have converted anyway (persuadables vs. doomed vs. sure things).

This engagement bridges rigorous econometric causal modeling (DoWhy, EconML Double Machine Learning) with executive-facing Power BI analytics. We isolate the true **Average Treatment Effect (ATE)** and **Heterogeneous Treatment Effects (HTE)**, allowing executive stakeholders to simulate counterfactual financial interventions before risking real capital.

---

## 2. Core Methodological Architecture
Our custom-built technical stack guarantees unconfounded causal inference and seamless executive visualization:
* **Econometric Identification:** Pearlian causal graphs and back-door criterion adjustment using `DoWhy`.
* **Causal Machine Learning:** Double Machine Learning (`EconML`) combined with non-linear tree-based nuisance estimators to eliminate confounding bias.
* **Semantic BI Integration:** Customer-level analytical feeds (`causal_dashboard_feed.csv`) piped directly into Power BI with custom DAX measures translating treatment effects into Annual Recurring Revenue (ARR) and targeted ROI.

## 3. Scope of Work & Phased Deliverables

### Phase 1: Causal Discovery & Data Pipeline (Week 1 - 2)
* Audit existing enterprise data warehouses (CRM, billing logs, customer telemetry).
* Construct formal Directed Acyclic Graphs (DAGs) mapping known confounders and treatment variables.
* Build automated synthetic/production data preprocessing pipelines in Python (`venv`, `pandas`, `scikit-learn`).

### Phase 2: Double Machine Learning & HTE Engine (Week 3 - 4)
* Train robust Double Machine Learning models to calculate granular Individual Treatment Effects (ITE).
* Benchmark model robustness via placebo tests and sensitivity analysis.
* Export segmented customer uplift metrics across SMB, Mid-Market, and Enterprise tiers.

### Phase 3: Executive Power BI Dashboard & Handover (Week 5)
* Deploy the executive-facing Power BI data model.
* Implement custom DAX measures for real-time financial simulation (Incremental ARR, Causal Uplift, Campaign ROI).
* Deliver a comprehensive technical handover, GitHub repository documentation, and executive training session.
